# NGU Digest 百科猜字游戏 & 视频后期制作工具

读取百科文本内容，将文字隐藏为黑方块，通过猜字逐步揭示内容的互动工具。本项目服务于 **NGU Digest** 视频企划，支持**前期玩家游戏录制**与**后期视频素材批量导出**。

---

## 🌟 分支定位 (`post-prod`)

当前分支 `post-prod` 专为**视频后期制作 (Post-Production)** 量身定制：
- 默认路由进入 **上帝视角后期模式 (God Mode)**，可加载文章、双向同步点击解密，并一键录制点开顺序与批量导出 1920p 高清图片。
- 仍可通过导航切换至 **原版游戏模式 (/classic)** 进行前期单人/多人游玩。

---

## 🎬 核心功能（后期制作模式 - God Mode）

### 1. 上下分栏双向互动视窗
- **上半区：视频呈现区 (Game View)**
  - 纯净模拟视频画面，字符由黑方块遮罩。
  - 配备定制题目周边 SVG 装饰边框（`question-boarder.svg`），1920px 全宽贴合，高度自由调节。
  - 移除了所有与最终成片无关的输入框、错误猜字区、计分与页脚，确保视频画面 100% 纯净。
- **下半区：上帝视角参考区 (God View)**
  - 明文展示全文供后期人员直接观察，已点开的字符呈高亮状态，未点开的呈柔和状态。
- **双向联动点击与悬浮**：
  - 点击上半区黑方块或下半区明文中的任意字符，**全篇相同字符立即同步揭示/隐藏**。
  - 鼠标悬停任意字符，双区全篇相同字符同步金色光晕高亮对照。

### 2. 1080p 视频录屏视窗与排版模拟
- **固定 1920px 宽度**，支持常见视频高度预设：
  - `540p`（半屏，默认）
  - `500p`（边框原生高）
  - `1080p`（全屏）
  - `自适应`（根据文本内容自动撑开）
  - 支持直接输入像素数值，或通过中间分割条和底部手柄自由上下拖拽分配高度。
- **文字排版与样式控制**：
  - 全站采用统一字体 **Noto Sans SC**。
  - **弹性垂直居中（Flex Vertical Center）**：文字自动在边框内垂直居中，无论框高多大皆处于最佳视觉中心，内容过多时自动平滑滚动。
  - **对齐切换**：支持标准靠左对齐与水平居中对齐。
  - **实时微调**：字号大小（14~38px）、字块间距（0~10px）。
- **背景抠像主题**：
  - 经典白底（Light）
  - 暗黑模式（Dark）
  - 绿幕抠像（Chroma Green `#00FF00`）
  - 蓝幕抠像（Chroma Blue `#0000FF`）
  - 透明背景（Transparent）

### 3. 🎬 点开顺序保存与 1920p 图片批量导出
- **自动记录点开序列**：
  - 按点击先后顺序实时追踪记录步骤（例如：`01 地 x3` → `02 力 x2` → `03 游 x1`...）。
  - 支持单步预览、单步删除、撤回最后一步、清空序列。
- **1:1 逐帧无损高清导出**：
  - 导出目标为**视频呈现区**，宽度固定为 **1920px**，高度严格跟随当前设置的呈现区高度。
  - **标准文件命名规则**：
    - `00_{标题}_初始.png`（可选包含第 00 步全遮罩初始画面）
    - `01_{标题}_{字}.png`
    - `02_{标题}_{字}.png`
    - `03_{标题}_{字}.png`...
    - （例如：`00_地力_初始.png`、`01_地力_地.png`、`02_地力_力.png`）
  - **ZIP 压缩包打包下载**：一键生成标准命名规范的 `.zip` 压缩包，避免浏览器多次下载拦截；同时支持逐张下载 PNG。

## ⌨️ 快捷键列表

| 快捷键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **`Space`（空格键）** 或 **`R` 键** | **开始 / 暂停录制点开顺序** | 非文本输入状态下切换录制状态 |
| **`Ctrl + E`** / **`Cmd + E`** | **呼出批量导出弹窗** | 快速进入 1920p 图片导出界面 |
| **`Esc`** | **关闭弹窗** | 退出导出对话框 |
| **`Ctrl + Z`** | **撤销上一步操作** | 撤销字符揭示/隐藏 |
| **`Ctrl + Y`** / **`Ctrl + Shift + Z`** | **重做操作** | 恢复撤销的步骤 |

## 🎮 原版游戏模式（前期录制 - /classic）

- **单人模式**：上传百科文本，猜出标题中所有字即算通关。
- **多人对战（2~6人）**：
  1. 玩家轮流输入猜字。
  2. 猜中任何字得 1 分，猜中标题中的字获得额外回合奖励。
  3. 猜错或仅命中正文则换下一位玩家。
  4. 最终揭晓标题最后一个字的玩家获胜。

## 🚀 快速开始

```bash
# 1. 安装依赖（已集成 html-to-image 与 jszip）
npm install

# 2. 启动开发服务器
npm run serve
# 或 npm run dev

# 3. 生产环境构建打包
npm run build
```

浏览器访问 `http://localhost:5173` 即可进入上帝视角后期制作模式。

## 🛠️ 技术栈

- **前端框架**：Vue 3 + Composition API
- **语言**：TypeScript
- **构建工具**：Vite 4
- **路由**：Vue Router 4
- **样式**：CSS3 / SCSS
- **离线图像捕获**：`html-to-image`
- **ZIP 压缩打包**：`jszip`
- **默认字体**：Google Fonts Noto Sans SC
